\# DSA Assignment 1

\## Expression Conversion and Evaluation



This program takes an infix expression, converts it to postfix notation and evaluates the result.



\## How to Compile

g++ -std=c++17 -o assignment1 BSEF24A037\_ASSIGNMNET\_1\_.cpp



\## How to Run

./assignment1



\## Example

Input:  a + b \* (c + 2)

Output: a b c 2 + \* +

&#x20;       23



\## Supported

\- Operators: + - \* /

\- Brackets: () \[] {}

\- Variables following C++ identifier rules

\- Integer constants
